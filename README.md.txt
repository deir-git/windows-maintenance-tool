# Windows Maintenance Tool

Ferramenta desenvolvida para auxiliar técnicos de suporte na manutenção e diagnóstico de computadores Windows.

## Funcionalidades

- Diagnóstico de rede
- Teste de DNS
- Teste de Gateway
- Ping Internet
- Verificação de arquivos do sistema (SFC)
- Reparo de imagem do Windows (DISM)
- Verificação de disco (CHKDSK)
- Limpeza de arquivos temporários
- Geração automática de logs
- Solicitação automática de administrador

## Tecnologias

- Windows Batch (.bat)
- CMD
- PowerShell

## Objetivo

Automatizar tarefas repetitivas de suporte técnico e reduzir o tempo de diagnóstico.
